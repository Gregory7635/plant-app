# 11 — Руководство пользователя

Подробное руководство пользователя — см. [user-guide.md](user-guide.md)

## Краткая инструкция

1. Зарегистрируйтесь на странице `/register`
2. Войдите в систему через `/login`
3. На главной странице выберите фото растения и нажмите «Определить»
4. Просматривайте историю запросов в разделе «История»
