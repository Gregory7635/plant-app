# Глоссарий

| Термин | Определение |
|---|---|
| **Идентификация растения** | Процесс определения вида растения по фотографии с помощью Plant.id API |
| **Plant.id API** | Внешний REST-сервис компьютерного зрения для классификации растений |
| **Wikipedia API** | Внешний API для получения описания растений из Википедии |
| **Вероятность идентификации** | Числовой показатель уверенности модели (0.0–1.0) в правильности определения |
| **История запросов** | Список прошлых идентификаций, привязанных к аккаунту пользователя |
| **PCMEF** | Архитектурный паттерн: Presentation–Control–Mediator–Entity–Foundation |
| **BCrypt** | Алгоритм хеширования паролей, используемый в системе |
| **ROLE_USER** | Базовая роль: доступ к идентификации, истории и профилю |
| **ROLE_ADMIN** | Расширенная роль: управление пользователями и данными |
| **WAR** | Web Application Archive — формат деплоя Java веб-приложений на Tomcat |
| **JWT** | JSON Web Token — формат токена аутентификации (применяется в REST) |
| **Data Mapper** | Паттерн, разделяющий бизнес-объекты и схему БД |
| **Identity Map** | Паттерн, гарантирующий уникальность объекта в рамках сессии |
