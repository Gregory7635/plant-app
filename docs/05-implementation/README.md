## Описание

На данном этапе реализованы все компоненты приложения в соответствии с архитектурой PCMEF.

### Паттерны рефакторинга

| Паттерн | Реализация |
|---|---|
| **Data Mapper** | JPA + Hibernate отделяет бизнес-объекты (`Plant`, `User`, `Identification`) от таблиц БД |
| **Identity Map** | Hibernate Session Cache обеспечивает уникальность объектов в рамках транзакции |
| **Lazy Load** | Связи `@ManyToOne` загружаются лениво (`fetch = FetchType.LAZY`) |

### Статический анализ

Проект проходит компиляцию без ошибок. Используется Lombok для уменьшения boilerplate-кода.
