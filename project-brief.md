# Техническое задание: Веб-приложение для идентификации растений




## 1. Суть проекта

Веб-приложение, которое позволяет пользователю загружать фото растения и получать его идентификацию через **Plant.id API** 
(уже есть работающий Telegram-бот на этом API — нужно перенести логику в веб).
---

## 2. Технологический стек 

| Компонент | Технология |
|---|---|
| Язык (сервер) | **Java 17+** |
| Фреймворк | **Spring Boot** (или Servlets + JSP) |
| Клиент | **HTML + CSS + JavaScript** (или JSP/Thymeleaf) |
| База данных | **PostgreSQL** |
| ORM | **Spring Data JPA / Hibernate** |
| Сборка | **Maven или Gradle** |
| Деплой | **WAR-файл на Tomcat** |

> Другие языки (Python, Node.js и т.д.) — **не допускаются**. Только Java на сервере.

---

## 3. Архитектура — PCMEF 

Весь код должен быть разбит на 5 слоёв. Зависимости **только сверху вниз**:

```
Presentation (P)  →  Control (C)  →  Mediator (M)  →  Entity (E)  →  Foundation (F)
     UI               Контроллеры      Сервисы         JPA-сущности    Репозитории
```

**Что каждый слой делает и чего НЕ делает:**

| Слой | Делает | НЕ делает |
|---|---|---|
| Presentation | HTML-страницы, отображение | Бизнес-логику |
| Control | Обработка HTTP-запросов, валидация | Прямые запросы к БД |
| Mediator | Бизнес-логика, транзакции, вызов Plant.id API | Знает о Presentation |
| Entity | Java-классы сущностей с бизнес-методами | Логику доступа к данным |
| Foundation | Репозитории, SQL, JPA | Бизнес-правила |

## 4. Функциональные требования

### Обязательные 

- **5+ веб-страниц:**
  - Главная / лендинг
  - Загрузка фото + результат идентификации
  - История запросов пользователя
  - Карточка растения (детали)
  - Страница регистрации/входа
  - (опционально) Профиль пользователя

- **Аутентификация и авторизация:**
  - Форма входа/регистрации
  - Хеширование паролей через BCrypt
  - Роли: `ROLE_USER` и `ROLE_ADMIN`
  - Защита от XSS и SQL-инъекций
  - Сессии или JWT-токены

- **CRUD для основных сущностей** (минимум для истории запросов, избранного)

- **REST API** (минимум 8 эндпоинтов):

- **Адаптивная вёрстка** (работает на мобильном и десктопе)

- **Валидация** на клиенте (JavaScript) и на сервере

- **AJAX-запросы** для динамического обновления (без перезагрузки страницы)

## 5. База данных

- Нормализация до **3NF**
- Первичные и внешние ключи везде
- Индексы на часто используемых полях
- Ограничения: NOT NULL, UNIQUE, CHECK где нужно
