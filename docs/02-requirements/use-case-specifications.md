# Спецификации Use Case

## UC4: Идентификация растения по фотографии

| Поле | Значение |
|---|---|
| **ID** | UC4 |
| **Название** | Загрузка фото для идентификации растения |
| **Актор** | Аутентифицированный пользователь |
| **Предусловие** | Пользователь авторизован, находится на главной странице |
| **Постусловие** | Результат идентификации отображён и сохранён в истории |

**Основной поток:**
1. Пользователь выбирает файл изображения
2. Пользователь нажимает «Определить растение»
3. Система отправляет изображение (base64) в Plant.id API
4. Plant.id API возвращает название растения и вероятность
5. Система запрашивает описание из Wikipedia API
6. Система сохраняет запись `Identification` в БД
7. Система отображает страницу с результатом

**Альтернативный поток (ошибка API):**
- 3a. Plant.id API недоступен → система показывает сообщение об ошибке

## UC2: Регистрация пользователя

| Поле | Значение |
|---|---|
| **ID** | UC2 |
| **Актор** | Гость |
| **Предусловие** | Пользователь не авторизован |
| **Постусловие** | Создан аккаунт с ролью ROLE_USER |

**Основной поток:**
1. Гость открывает страницу `/register`
2. Вводит username и пароль
3. Система проверяет уникальность username
4. Система хеширует пароль через BCrypt
5. Система сохраняет пользователя в БД
6. Пользователь перенаправляется на `/login`

**Альтернативный поток (username занят):**
- 3a. Система показывает ошибку «Пользователь уже существует»
