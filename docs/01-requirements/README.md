## Функциональные требования

| ID | Требование |
|---|---|
| FR-01 | Пользователь может зарегистрироваться и войти в систему |
| FR-02 | Пользователь может загрузить фото растения |
| FR-03 | Система идентифицирует растение через Plant.id API |
| FR-04 | Система получает описание растения из Wikipedia |
| FR-05 | Результат идентификации сохраняется в БД |
| FR-06 | Пользователь может просматривать историю своих запросов |
| FR-07 | Пользователь может перейти на карточку растения |
| FR-08 | Администратор имеет доступ к управлению данными |

## Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-01 | Пароли хешируются через BCrypt |
| NFR-02 | Защита от XSS и SQL-инъекций |
| NFR-03 | Адаптивный интерфейс (Bootstrap) |
| NFR-04 | Покрытие тестами > 40% (JaCoCo) |
