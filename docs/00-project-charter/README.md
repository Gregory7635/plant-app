## Описание этапа

На данном этапе проведён бизнес-анализ предметной области. Определены участники системы, основные процессы и цель проекта.

**Цель системы:** предоставить пользователю инструмент для идентификации растений по фотографии с сохранением истории запросов.

**Участники:**
- Пользователь (незарегистрированный / зарегистрированный)
- Администратор
- Внешние сервисы: Plant.id API, Wikipedia API
