# Руководство пользователя

## Начало работы

### 1. Регистрация

1. Откройте приложение по адресу `http://localhost:8080`
2. Нажмите **«Регистрация»** в навигации
3. Введите логин и пароль (минимум 4 символа)
4. Нажмите **«Зарегистрироваться»**

### 2. Вход

1. Нажмите **«Войти»**
2. Введите логин и пароль
3. Нажмите **«Войти»**

---

## Идентификация растения

1. На главной странице нажмите **«Выбрать файл»**
2. Выберите фотографию растения (JPEG/PNG, до 10 MB)
3. Нажмите **«Определить растение»**
4. Дождитесь результата (обычно 2–5 секунд)

На странице результата отображается:
- Название растения (латинское)
- Вероятность определения (%)
- Описание из Wikipedia
- Ссылка на статью Wikipedia
