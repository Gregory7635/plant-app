## Страницы приложения

| Страница | URL | Описание |
|---|---|---|
| Главная | `/` | Лендинг, последние определения |
| Идентификация | `/` (форма) | Загрузка фото через AJAX |
| Результат | `/identify` (POST) | Результат идентификации |
| История | `/history` | История запросов пользователя |
| Карточка растения | `/plants/{id}` | Детали растения, ссылка на Wikipedia |
| Вход | `/login` | Форма авторизации |
| Регистрация | `/register` | Форма регистрации |

## Особенности UI

- Адаптивная вёрстка на **Bootstrap 5**
- AJAX-загрузка формы идентификации (Fetch API, без перезагрузки страницы)
- Спиннер загрузки во время запроса к API
- Валидация форм на клиенте (JavaScript) и на сервере (Spring)
